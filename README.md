#Verifix
Verifix is a trusted local services app. Book verified plumbers, electricians, tutors and more in one tap. See nearby workers on a live map, get a fair price upfront, track arrival, and rate real jobs. Every provider is ID-verified and backed by repeat customers. Verified. Fixed.

## Run locally

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Open the local URL printed by Vite (by default, <http://localhost:5173/>).

The app runs in local simulation mode when Supabase credentials are not configured.
